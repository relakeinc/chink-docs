# Chink

Chink es un sistema web de gestión de inventario para microempresas, como tiendas de barrio, minimercados o papelerías. Permite registrar productos, llevar el stock por almacén, registrar entradas, salidas, transferencias y ajustes, recibir alertas de stock bajo, ver reportes, manejar el equipo de trabajo con roles y llevar el control de los pagos que reportan los clientes.

Este proyecto lo desarrollamos para la asignatura de Ingeniería de Software en la Universidad Santiago de Cali, siguiendo el modelo en cascada y el estándar IEEE 830 para los requisitos.

La aplicación está publicada en [chink.relake.co](https://chink.relake.co).
